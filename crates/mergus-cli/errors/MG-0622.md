# MG-0622 · Steps of one file read each other in a cycle

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0614

## Cause
The steps of a `.py` model read each other through their parameters, and some of them form a
cycle, so none of them can run first. The error names the file, the line of the first step of
the cycle and every step of it.

## Example
`models/orders.py` line 9: steps `ping` -> `pong` -> `ping` form a cycle

## Fix
Remove one parameter of the cycle, so that one of its steps no longer reads the next.
