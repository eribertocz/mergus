# MG-0615 · A seed has an unknown key

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0645

## Cause
A `[seeds.<name>]` of `project.toml` has a key other than `columns`, `delimiter` and
`header`. The error names the line and the key, and the closest allowed key when one is
close.

## Example
`project.toml` line 4: unknown seed key `seeds.countries.delimeter`; did you mean `delimiter`?

## Fix
Remove the key, or correct its name to `columns`, `delimiter` or `header`.
