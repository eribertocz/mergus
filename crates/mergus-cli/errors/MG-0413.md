# MG-0413 · A table declares a delete detection it cannot run

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0415

## Cause
A table of a source file declares `deletes = "compare"` without a `key`, so there is nothing to
compare the keys of the source with, or declares `delete_window` without an `incremental`
column of a date or time type (`DATE`, `TIMESTAMP` or `TIMESTAMPTZ`), so the window cannot be
counted. `mergus validate` refuses the first and a `delete_window` without `incremental`; the
type of the incremental column is checked when the table is read, before any row is. The error
names the source, the table and the option.

## Example
`sources/erp.toml` line 5: table `sales` of source `erp` declares `deletes` but no `key`;
`compare` compares the keys of the source with raw

## Fix
Declare the table's `key` for `compare`, or a date or time `incremental` column for
`delete_window`, or remove the option.
