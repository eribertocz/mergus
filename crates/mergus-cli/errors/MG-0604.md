# MG-0604 · A macro file holds more than macros

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0641

## Cause
A file of `macros/` holds a statement that DuckDB refuses, or creates an object other than a
macro. Mergus runs each macro file in its own fresh DuckDB session, with external access off
and the configuration locked, so no file, network, `ATTACH`, `INSTALL`, `LOAD` or `SET` can
succeed. Afterwards the session must hold only new macros. Text templating is not DuckDB SQL,
so DuckDB refuses it. The error names the file and repeats DuckDB's refusal, or names the
catalog functions that show the other objects.

## Example
`macros/finance.sql`: it creates objects other than macros, seen in `duckdb_tables()`; a macro
file holds only CREATE MACRO statements

## Fix
Keep only `CREATE MACRO` statements in the file, scalar or table, and move anything else to a
model.
