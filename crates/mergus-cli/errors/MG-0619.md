# MG-0619 · A Polars model file did not load

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0617

## Cause
Mergus runs a Polars step in a Python child that imports the model's file by its path, then
looks up the step's function in it. Importing the file raised an exception, for example in
its top-level code or in one of its imports, or the file has no function with the step's
name. The error names the model, the file, and the exception's type and message.

## Example
MG-0619: model `sales`, file `models/gold/sales.py` did not load: ModuleNotFoundError: No
module named 'helpers'

## Fix
Fix the file so that it imports without an error and defines the step's function, then run
again.
