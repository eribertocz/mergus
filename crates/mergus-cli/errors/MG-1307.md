# MG-1307 · A file to create already exists

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1349, MG-REQ-1350

## Cause
A file that `mergus init`, `mergus new model` or `mergus add source` creates already exists:
`project.toml` or `.gitignore` for `init`, the model or source file for the others. The
command never replaces a file, so it writes nothing.

## Example
`mergus init` in a folder that already holds `project.toml`.

## Fix
Choose another name or folder, or move the existing file away first.
