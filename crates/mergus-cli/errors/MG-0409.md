# MG-0409 · The impact of a source is unknown

- Exit code: 0
- Retryable: no
- Rules: MG-REQ-0432

## Cause
A warning of `mergus plan`: to show what reading each table costs, `plan` attaches each
database source read-only and reads its row estimates and indexes. The source could not be
reached or read, for example because its secret is missing or the server is down. `plan`
still writes the plan, shows `unknown` for the estimated rows and the index of each of its
tables, and gives the reason. It does not change the exit code.

## Example
The estimated rows and indexes of source `erp` are unknown: MG-1003 secret reference
`secret:erp` is not set.

## Fix
Fix the reason given, then run `mergus plan` again. The window and the load budget are shown
either way.
