# MG-0612 · The project's Python cannot import polars

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0617

## Cause
Polars steps run in a Python child started with the project's interpreter: the configured
`[python] interpreter`, else the project's `.venv`, else `python3` on the search path. That
interpreter cannot import `polars`, so the step cannot be planned or run.

## Example
MG-0612: model `sales`, step `in_usd`: the project's Python cannot import `polars` (No module
named 'polars'); install polars in the project's Python

## Fix
Install polars in the project's Python, for example `.venv/bin/python -m pip install polars`,
then run again.
