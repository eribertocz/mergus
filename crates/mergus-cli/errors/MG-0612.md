# MG-0612 · A macro name clashes

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0642

## Cause
Two macros of the project have the same name, or a macro has the name of a built-in
function. Names are compared without case. A built-in is a function DuckDB has in a fresh
session before any macro file runs, where extensions that are not loaded do not count, or a
macro of Mergus itself, such as `as_of`. A model that
calls the name could not tell which function it gets. The error names both files, or the file
and the built-in.

## Example
macro `safe_div` is defined twice: `macros/finance.sql` and `macros/math.sql`

## Fix
Rename one of the macros, and the calls to it, so that every macro has its own name.
