# MG-1312 · A setting has an invalid value

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1351

## Cause
`max_parallel` is not an integer from 1. The message names where the value comes from: the
flag `--max-parallel`, the variable `MERGUS_MAX_PARALLEL` or the user configuration file.

## Example
`mergus plan --max-parallel 0`.

## Fix
Give an integer from 1, such as `4`, or remove the value to use the default.
