# MG-0306 · Expression in a configuration value

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0317, MG-REQ-0364

## Cause
A string value of a configuration file contains `${`, `{{` or `{%`. Configuration values are
literals: there are no variables, expressions or includes. The error names the file, the line
and the key.

## Example
`project.toml` line 4: key `gold.location` holds `s3://${zone}`.

## Fix
Write the literal value. Values that change per run are run parameters, such as `$run_date`.
