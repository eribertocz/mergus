# MG-0310 · `ids.toml` is invalid

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0370

## Cause
`ids.toml` at the project root is not valid TOML 1.0, or it has something other than the
tables `[model]` and `[source]` mapping a name to an identifier: another table, a key outside
those tables, or a value that is not a string made of the prefix of its table (`mdl` or
`src`), `_` and 16 lowercase base32 characters. The error names the file, the line and the key.

## Example
`ids.toml` line 2: key `model.fact_orders` is not a model identifier: a string `mdl_` and 16
lowercase base32 characters

## Fix
Keep only `[model]` and `[source]`, and give each entry the identifier the object had before it
was renamed, for example `fact_orders = "mdl_2x7kq4m9a1bc3def"`.
