# MG-0307 · A float is NaN or infinite

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0365

## Cause
A float of a configuration file is `nan`, `inf` or `-inf`, which canonical JSON cannot hold.
The error names the file, the line and the key.

## Example
`sources/crm.toml` line 1: key `f` is `nan`.

## Fix
Write a finite number.
