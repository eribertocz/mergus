# MG-1001 · A secret value is empty

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1007

## Cause
`mergus secret set` read an empty value: standard input was empty, held only a line ending,
or the line typed on the terminal was empty. An empty secret would make every connection
that references it fail later, far from its cause, so nothing is stored.

## Example
secret `secret:crm` was not stored: the value is empty

## Fix
Write the value on standard input, for example `mergus secret set crm < crm.txt`, or type it
at the prompt.
