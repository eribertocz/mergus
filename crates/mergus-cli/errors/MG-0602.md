# MG-0602 · SQL names a parameter that is not a run parameter

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0603

## Cause
A `.sql` model names a parameter other than the run parameters `$run_date` (a `DATE`),
`$period_start` and `$period_end` (both `TIMESTAMPTZ`). The run binds only those. The error
names the file, the line and column of the parameter and the parameter.

## Example
`models/marts/fact_sales.sql` line 3 column 16: parameter `$min_amount` is not a run
parameter; use `$run_date`, `$period_start` or `$period_end`

## Fix
Use one of the run parameters, or write the value in the query or in a table it reads.
