# MG-1306 · The name of a new model is taken

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1350

## Cause
`mergus new model` was given the name of a model the project already has, in another folder.
Model names are unique in a project, whatever their folder, so nothing is written.

## Example
`mergus new model orders` when `models/staging/orders.sql` exists.

## Fix
Choose a name no model of the project has.
