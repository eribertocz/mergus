# MG-1305 · A name given to a command is not a lowercase identifier

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1349, MG-REQ-1350

## Cause
`mergus init`, `mergus new model` or `mergus add source` was given a project, model, schema
or source name that does not match `^[a-z][a-z0-9_]{0,62}$`, or `mergus init` derived from
the folder name a project name that does not. Nothing is written.

## Example
`mergus new model Orders`: `Orders` has an upper-case letter.

## Fix
Use the valid name the message suggests, for example `mergus new model orders`.
