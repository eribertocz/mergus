# MG-0606 · The by column of a history model is not a date or a timestamp

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0663

## Cause
A history model has `by = "<column>"`, and that column of its input is not a `DATE`,
`TIMESTAMP` or `TIMESTAMPTZ`. Its value becomes the `_valid_from` of each new version, so it
must be a point in time. The run stopped before any row was written.

## Example
the `by` column `version` of the history table `dim_customer` is `BIGINT`, not DATE, TIMESTAMP or TIMESTAMPTZ

## Fix
Point `by` at a date or timestamp column, such as `updated_at`, or use a list of columns,
`by = ["version"]`, to detect changes by difference, then run again.
