# MG-0606 · A seed is not declared

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0645

## Cause
A `seeds/<name>.csv` file has no `[seeds.<name>]` in `project.toml`. Each seed declares its
column types, so that it loads as `raw.seed__<name>` with the same types every time. The error
names the CSV file.

## Example
seed `seeds/countries.csv` is not declared; add `[seeds.countries]` with its column types to
`project.toml`

## Fix
Add `[seeds.<name>]` to `project.toml` with `columns`, each column name to its DuckDB type, or
remove the file.
