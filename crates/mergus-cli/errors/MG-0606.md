# MG-0606 · A model cannot be backfilled

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0657

## Cause
`mergus backfill <model> --from <date> [--to <date>]` recomputes whole periods of the model's
`partition_by` grain. A model with no `partition_by` has no periods to recompute. A `history`
model can be backfilled only when the run confirms the rebuild of its history, because a
backfill rebuilds every version it holds.

## Example
MG-0606: model `fact_sales` cannot be backfilled: it has no `partition_by`; give it
`partition_by = "<column>:<grain>"`

## Fix
Give the model `partition_by = "<column>:<grain>"`, or for a `history` model confirm the
rebuild of its history. Otherwise run it without a backfill.
