# MG-0401 · Incremental table without a key

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0414

## Cause
A table of a source file declares `incremental` but no `key`. An incremental load merges the
new and changed rows into those already loaded, and it needs the business key to match them.
The error names the file, the line of `incremental`, the table and the source.

## Example
`sources/erp.toml` line 7: table `sales` of source `erp` is incremental but declares no
`key`.

## Fix
Add `key` to the table, a column or a list of columns, or remove `incremental` to load the
whole table each time.
