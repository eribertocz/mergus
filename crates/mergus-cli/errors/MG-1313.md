# MG-1313 · The user configuration file is not valid

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1351

## Cause
The user configuration file `config.toml` is not TOML, or holds a key Mergus does not know.
In phase 0.2 its only key is `max_parallel`.

## Example
`max_paralel = 2` in `~/.config/mergus/config.toml`.

## Fix
Remove or rename the key the message names, or fix the TOML syntax it reports.
