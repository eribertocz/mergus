# MG-1302 · No project found

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1344

## Cause
A command that reads a project found no `project.toml` in the current directory or in any
directory above it.

## Example
`mergus validate` run in `/tmp`, where neither `/tmp` nor `/` holds a `project.toml`.

## Fix
Run `mergus init` to create a project, or run the command inside a project directory.
