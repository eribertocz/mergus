# MG-0302 · A name is not a lowercase identifier

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0305, MG-REQ-0360

## Cause
A model, folder, schema, source or seed name does not match `^[a-z][a-z0-9_]{0,62}$`. The
error suggests a valid name.

## Example
`models/gold/Sales-EU/orders.sql`: the schema `Sales-EU` has uppercase letters and a `-`.

## Fix
Rename it to the suggested name, here `models/gold/sales_eu/orders.sql`.
