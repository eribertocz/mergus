# MG-0411 · The delete column of a table is missing from the source

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0415

## Cause
A table of a source file declares `deletes = "column:<name>"`, so Mergus reads deletes from that
logical-delete column of the source table, but the source table has no column of that name.
Mergus checks the columns before it reads any row, so nothing of the table is read and the load
is recorded as failed. The error names the source, the table and the column.

## Example
Table `sales` of source `erp` declares `deletes = "column:removed"` but the source table has no
column `removed`.

## Fix
Name the source's logical-delete column in `deletes`, or declare `compare` to compare keys with
the source, or `none` to ignore deletes.
