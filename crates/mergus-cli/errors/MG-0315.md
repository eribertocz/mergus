# MG-0315 · Models read one another in a cycle

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0375

## Cause
The references of `.sql` models form a cycle: a model reads, directly or through other
models, a model that reads it back, or a model reads itself. Models run in the order of their
references, so a cycle has no order. The error names every model of the cycle in reference
order, starting from the first in name order, with the file and line of each reference of the
cycle.

## Example
models `stg_a` -> `stg_b` -> `stg_a` form a cycle: `models/staging/stg_a.sql` line 2 reads
`stg_b`; `models/staging/stg_b.sql` line 4 reads `stg_a`

## Fix
Remove one reference of the cycle: read its table from a source or a seed, or move the shared
logic to a new model that both read.
