# MG-0102 · The DuckDB session has the icu extension loaded

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0180

## Cause
A DuckDB step found the `icu` extension loaded in its session. DuckDB keeps only the instant
of a `TIMESTAMP WITH TIME ZONE`; without `icu` it gives the instant back in UTC, and Mergus
puts the declared time zone back on it. With `icu`, DuckDB gives it back in the session's
time zone, which can be the host's, so the same step could produce different zones on
different machines. Mergus never loads `icu`, so the step failed before it ran.

## Example
the DuckDB session has the `icu` extension loaded, so time zones would depend on the host

## Fix
Remove whatever loads `icu` into the session, such as a `LOAD icu` statement in a macro file,
then run again.
