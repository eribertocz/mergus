# MG-0314 · SQL is not one read-only query

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0308, MG-REQ-0374

## Cause
A `.sql` model is not exactly one `SELECT` that DuckDB can parse, or it reads files, URLs or
the environment: it calls a table function other than `range`, `generate_series` and
`unnest`, reads a table whose name is not a lowercase identifier (such as `'file.csv'`), or
calls `getenv`, `nextval`, `currval` or `setseed`. A model only reads the tables Mergus gives
it. The error names the file, the line and column and the rejected construct.

## Example
`models/staging/stg_orders.sql` line 2 column 6: table function `read_csv` is not allowed; a
model is exactly one read-only SELECT

## Fix
Remove the construct: declare files and URLs as a source in `sources/<source>.toml` and read
them as `raw.<source>__<table>`.
