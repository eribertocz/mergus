# MG-1304 · Internal error

- Exit code: 10
- Retryable: no
- Rules: MG-REQ-1324

## Cause
Mergus found a defect in itself: a bundled schema cannot be used, an event it built does not
match the `mergus_events` contract, or its output cannot be written.

## Example
An event lacks a field its type requires, so it cannot be emitted.

## Fix
Report the message in an issue of the Mergus repository, with the command you ran.
