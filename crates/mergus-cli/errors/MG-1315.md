# MG-1315 · An idempotency key is claimed by a call still running

- Exit code: 3
- Retryable: yes
- Rules: MG-REQ-1313

## Cause
A command that changes state was given `--idempotency-key` with a key that another call
claimed less than 24 hours ago and has not finished. The key's record in
`.mergus/idempotency/` says the call is running, and a key stands for one call only. Nothing
is done.

## Example
`mergus run --idempotency-key nightly` in two terminals at the same time.

## Fix
Wait for the running call to end, then run the command again with the same key to get its
result.
