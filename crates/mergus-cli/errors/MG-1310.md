# MG-1310 · A model or a source does not exist

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1305, MG-REQ-1352

## Cause
A selector, or `mergus explain`, names a model or a source the project does not have. The
command stops before selecting or explaining anything.

## Example
`mergus ls stg_order` when the model is named `stg_orders`.

## Fix
Use the name the message suggests, or run `mergus ls` to list every model.
