# MG-0303 · A configuration file is not TOML 1.0

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0316, MG-REQ-0365

## Cause
`project.toml` or a `sources/*.toml` file is not valid TOML 1.0: a syntax error, a key
defined twice, an integer outside the 64-bit range, or bytes that are not UTF-8. The error
names the file and the line.

## Example
`project.toml` line 2: `name` is defined twice.

## Fix
Correct the TOML at that line.
