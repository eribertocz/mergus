# MG-0704 · A candidate cannot be used

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0705, MG-REQ-0707

## Cause
A run keeps its results, as candidates, in `.mergus/work/candidates/<fingerprint>/`: the rows
in `result.arrow`, then `complete.json`, each written to a temporary name and renamed. The
file system could not create, write, rename, list or delete a candidate. A candidate whose
`complete.json` was not renamed into place stays incomplete, and the next run deletes it. The
error carries the path and the file system's own message.

## Example
a candidate cannot be used at `.mergus/work/candidates/9f8e7d6c/complete.json`: No space left on device

## Fix
Check that the project's `.mergus/` folder is on a writable disk with free space, then run
again: complete candidates are reused.
