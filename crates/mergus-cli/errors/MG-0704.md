# MG-0704 · An incremental model has neither `partition_by` nor `key`

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0654

## Cause
A model with `refresh = "incremental"` must say what to recompute: the periods of its
`partition_by` column (MG-REQ-0652) or the rows of changed keys of its `key` (MG-REQ-0653).
This one declares neither, so the plan cannot be built.

## Example
MG-0704: model `fact_sales` has `refresh = "incremental"` but neither `partition_by` nor
`key`; set `partition_by = "<column>:<grain>"` to recompute periods, or `key` to merge by key

## Fix
Set `partition_by = "<column>:<grain>"` to recompute periods, or `key` to merge by key. A model
with both is incremental by period.
