# MG-0704 · The work zone cannot be used

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0503, MG-REQ-0705

## Cause
A run keeps its scratch files in `.mergus/work/runs/<run_id>/` and its results, as
candidates, in `.mergus/work/candidates/<fingerprint>/`. The file system could not create,
write, rename, list or delete one of them. A candidate whose `complete.json` was not renamed
into place stays incomplete, and the next run deletes it. The error carries the path and the
file system's own message.

## Example
the work zone cannot be used at `.mergus/work/candidates/9f8e7d6c/complete.json`: No space left on device

## Fix
Check that the project's `.mergus/` folder is on a writable disk with free space, then run
again: complete candidates are reused.
