# MG-0506 · Raw storage failed

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0511, MG-REQ-0514

## Cause
The storage adapter of the raw zone could not read or write a raw table, or could not commit.
The load is recorded in `ops.loads` as failed with this code, and the next load starts from
the last recorded watermark. The error carries the storage's own message.

## Example
raw storage failed: table `erp__sales` has no readable version `7`

## Fix
Check that the catalog and the data path of `[raw]` are reachable and writable, then run the
load again.
