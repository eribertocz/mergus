# MG-0621 · A step parameter takes any number of inputs

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0614

## Cause
A step has a `*args` or `**kwargs` parameter. Each input of a step is named by one parameter,
so a parameter that takes any number of values names no input. The error names the file, the
line, the step and the parameter.

## Example
`models/orders.py` line 1 column 24: parameter `*frames` of step `orders` takes any number of
inputs; name each input as its own parameter

## Fix
Name each input as its own parameter.
