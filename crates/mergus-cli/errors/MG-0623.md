# MG-0623 · A Python model has no function named like its file

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0615

## Cause
The step whose name equals the file stem is the model's result. The file has no such public
function, so the model has no result. The error names the file and the definition expected.

## Example
`models/gold/sales/sales_by_segment.py` has no function `sales_by_segment`; define
`def sales_by_segment(...)` for the model's result

## Fix
Define the function named like the file, or rename the step that is the result.
