# MG-0601 · DuckDB cannot prepare a SQL model

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0604

## Cause
DuckDB refuses to bind a `.sql` model against the schemas of its inputs: it names a column
that no input has, mixes types that do not match, or makes any other binder error. Mergus
checks every model this way, without data, before it runs anything. The error names the file
and repeats what DuckDB reports.

## Example
`models/marts/fact_sales.sql`: DuckDB cannot prepare the model: Binder Error: Referenced
column "amount" not found in FROM clause!

## Fix
Correct the query so that it matches the columns and types of the tables it reads.
