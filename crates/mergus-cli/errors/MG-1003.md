# MG-1003 · A secret reference does not resolve

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1001, MG-REQ-1004

## Cause
A source references a secret as `secret:<name>`, and neither link of the resolution chain
answers: the environment variable `MERGUS_SECRET_<NAME>` is not set, and the keychain has no
entry of service `mergus` and account `<name>`, or cannot be read. Every connection that uses
the reference would fail, so `mergus doctor` reports it before any run.

## Example
secret `secret:crm` was not found: the environment variable `MERGUS_SECRET_CRM` is not set
and the keychain has no entry of service `mergus` and account `crm`

## Fix
Run `mergus secret set <name>` to store the value in the keychain.
