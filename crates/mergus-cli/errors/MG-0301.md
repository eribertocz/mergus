# MG-0301 · Two models have the same name

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0303

## Cause
Two files under `models/` have the same stem. Model names are unique in the project,
whatever their folder.

## Example
`models/staging/customers.sql` and `models/gold/crm/customers.py` both define the model
`customers`.

## Fix
Rename one of the files, for example `models/staging/customers.sql` to
`models/staging/stg_customers.sql`.
