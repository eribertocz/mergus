# MG-0617 · A seed is large

- Exit code: 0
- Retryable: no
- Rules: MG-REQ-0646

## Cause
A warning: a seed has more than 10,000,000 bytes. Seeds are small reference tables kept with
the code, and each change of one changes the fingerprints of the models that read it. Data of
this size belongs in a source. The warning names the file and its size, and never fails the
read.

## Example
seed `seeds/postcodes.csv` has 12500000 bytes, more than 10,000,000; load data of this size
from a source instead

## Fix
Declare the data as a source in `sources/` and read it from there, or make the seed smaller.
