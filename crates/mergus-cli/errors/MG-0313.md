# MG-0313 · SQL names a table the project does not know

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0307, MG-REQ-0373

## Cause
A `.sql` model reads a table that is not a CTE of the query, a model of the project, a table
of a declared source (`raw.<source>__<table>`) or a seed (`raw.seed__<name>`). Names are
compared without case. The error names the file, the line and column of the reference and the
closest known name, when one is close enough.

## Example
`models/marts/fact_sales.sql` line 3 column 6: `stg_order` is not a model, source table or
seed of the project; did you mean `stg_orders`?

## Fix
Correct the name, or declare the table in `sources/<source>.toml` under `[tables.<table>]`.
