# MG-0620 · A step parameter names nothing the model can read

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0614

## Cause
Each parameter name of a step is an input: another step of the same file, a model, a raw
table or a seed, in that order. Raw tables and seeds are named without their schema, such as
`erp__sales` or `seed__countries`. A parameter that names none of them, or names its own step,
has no input. The error names the file, the line, the step and the parameter, and the closest
known name within 3 edits.

## Example
`models/orders.py` line 1 column 12: parameter `stg_ordrs` of step `orders` is not a step of
this file, a model, a raw table or a seed; did you mean `stg_orders`?

## Fix
Rename the parameter after the step, model, raw table or seed it reads.
