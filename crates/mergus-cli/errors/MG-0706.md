# MG-0706 · No DuckDB is available for a run

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0710

## Cause
`mergus run` and `mergus backfill` execute their steps in DuckDB, whose extensions live in the
user cache directory. The operating system gives no user cache directory, so no DuckDB can be
opened and nothing is executed.

## Example
`mergus run` with `HOME` unset and no `XDG_CACHE_HOME` on Linux.

## Fix
Set `HOME` to an absolute path, or `LOCALAPPDATA` on Windows, then run again.
