# MG-0706 · A backfill range is not valid

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0710

## Cause
`--from` or `--to` of `mergus backfill` is not a calendar date written `YYYY-MM-DD`, or `--to`
is before `--from`. The range of a backfill is widened to whole periods from these dates, so
each must be one and the range must not end before it starts. Nothing is planned or executed.

## Example
`mergus backfill fact_sales --from 2026-13-01`: there is no month 13.

## Fix
Write each date as `YYYY-MM-DD`, for example `--from 2026-01-01`, with `--to` not before it.
