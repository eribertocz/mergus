# MG-0706 · A backfilled model is not incremental by period

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0657

## Cause
`mergus backfill <model> --from <date> [--to <date>]` recomputes whole periods of the model's
`partition_by` grain. The model is not `refresh = "incremental"` with a `partition_by`, so it has
no periods to recompute.

## Example
MG-0706: model `fact_sales` cannot be backfilled: it is not incremental by period; give it
`refresh = "incremental"` and `partition_by = "<column>:<grain>"`

## Fix
Give the model `refresh = "incremental"` and `partition_by = "<column>:<grain>"`, or run it
without a backfill.
