# MG-1303 · A project file cannot be read

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1345

## Cause
The file system refused to read a file or directory of the project, for example because of
its permissions, or the current directory cannot be known.

## Example
`models/` exists but the user running `mergus validate` may not list it.

## Fix
Make every file and directory of the project readable by the user who runs Mergus, then run
the command again.
