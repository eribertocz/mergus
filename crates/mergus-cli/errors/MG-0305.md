# MG-0305 · Invalid configuration value

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0316, MG-REQ-0362, MG-REQ-0359

## Cause
A value of a configuration file has the wrong type or is not allowed by its schema, or a
required key is missing. The error names the file, the line, the key and what the schema
expects, with the closest allowed value when the value is one of a fixed list.

## Example
`project.toml` line 3: key `raw.location`: `3` is not of type `string`.

## Fix
Write a value of the expected type and form, or add the missing key.
