# MG-0412 · Rows arrived later than the overlap

- Exit code: 0
- Retryable: no
- Rules: MG-REQ-0420

## Cause
A warning: a `compare` of an incremental table found rows in the source that raw does not hold,
whose incremental value is older than the start of the reads, `watermark − overlap`. They arrived
after the loads that covered their value, so no incremental load will read them. Mergus counts
them and does not load them. The warning names the source, the table, the count, the start of
the reads and the oldest late value, with the command that loads them.

## Example
table erp.sales: 2 rows older than 2026-01-01 09:00:00 arrived late; run mergus backfill
--source erp --table sales --from 2026-01-01 05:00:00

## Fix
Run the suggested `mergus backfill` command to load them, and widen the table's `overlap` if
rows keep arriving this late.
