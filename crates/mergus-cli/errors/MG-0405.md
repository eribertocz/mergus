# MG-0405 · A source table changed in a breaking way

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0407

## Cause
Before a table of a database source is read, Mergus compares its columns with those of its last
load. A column of the last load is missing from the source, because it was dropped or renamed,
or a column changed type; in this phase every type change counts, widenings included. Raw could
not hold the new rows as they are, so the extraction of that table stops and nothing of it is
read; the other tables of the source load. The error names the source, the table, each column,
its old type and its new one.

## Example
Table `sales` of source `erp` changed since its last load: column `amount` changed type from
`DECIMAL(10,2)` to `VARCHAR`; column `note` (`VARCHAR`) was dropped or renamed.

## Fix
Restore the column, or its old type, in the source table, then run again. In this phase Mergus
does not follow a changed source schema into raw.
