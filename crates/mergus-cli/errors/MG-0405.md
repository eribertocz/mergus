# MG-0405 · Connection value sets a session parameter of Mergus

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0429

## Cause
Every PostgreSQL session of Mergus is protected: Mergus adds `application_name=mergus` and
`options=-c lock_timeout=5000` to the connection value of the source, in memory, so the
server sees who reads it and no statement waits more than 5 seconds for a lock. The
connection value of the source already sets one of these parameters, so Mergus refuses it
rather than depend on how libpq treats a repeated parameter. Nothing was sent to the server.
The error names the source and the parameter, never the value.

## Example
The connection value of source `erp` already sets `application_name`, which Mergus sets for
every source session.

## Fix
Remove `application_name` and `options` from the secret that holds the connection value of
the source.
