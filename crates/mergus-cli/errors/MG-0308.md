# MG-0308 · A section names no model of its folder

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0331

## Cause
A section of a folder `mergus.toml`, other than `[all]`, does not name a model file of the
same folder. The error names the file, the line of the section and the closest model name of
the folder, when one is close enough.

## Example
`models/sales/mergus.toml` line 4: section `fact_sale` names no model of this folder; did you
mean `fact_sales`?

## Fix
Rename the section to the model's file stem, or move it to the `mergus.toml` of the folder
that holds the model.
