# MG-0616 · A seed column has an unknown type

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0645

## Cause
A column of `[seeds.<name>].columns` has a type that is not a DuckDB column type name as
`DESCRIBE` writes it, such as `BIGINT`, `VARCHAR`, `DATE` or `DECIMAL(18,3)`. Type names are
written in uppercase. The error names the line, the column and the type given.

## Example
`project.toml` line 11: key `seeds.rates.columns.rate`: `decimal(18,3)` is not a DuckDB column
type as DESCRIBE writes it, such as `BIGINT` or `VARCHAR`

## Fix
Write the type as `DESCRIBE` writes it, such as `DECIMAL(18,3)`.
