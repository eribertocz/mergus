# MG-1311 · An error code does not exist

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1352

## Cause
`mergus explain` was given an argument of the form `MG-` and four digits that is not a code of
the error catalog.

## Example
`mergus explain MG-1399`.

## Fix
Use the code the message suggests, as printed by the error that sent you here.
