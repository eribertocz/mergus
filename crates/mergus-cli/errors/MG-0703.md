# MG-0703 · A published model uses an undeclared non-deterministic operation

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0720, MG-REQ-0722

## Cause
A step of a published model uses an operation that can return different results on the same
data: `LIMIT` without `ORDER BY` in the same `SELECT` (`limit_without_order`), `any_value`,
`random`, `now`, a Polars `.unique(` without `keep` (`unique_without_keep`) or `.first(` with
no earlier `.sort(` (`first_without_sort`). The model does not declare it in
`nondeterministic = [...]`, so the determinism gate of stage 4 blocks publication.

## Example
MG-0703: gate `determinism`, model `daily_sales`, step `query`: `random` at line 1, column 12
can return different results on the same data; fix: make it deterministic, or declare it
with `nondeterministic = ["random"]`

## Fix
Make the step deterministic, for example by adding an `ORDER BY` before the `LIMIT`, or
declare the operation by its name in the model's `nondeterministic = [...]`.
