# MG-0508 · The scratch directory of a run cannot be used

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0503

## Cause
A run keeps its intermediate files in its scratch directory, `.mergus/work/runs/<run_id>/`.
At its start it deletes every other directory under `.mergus/work/runs/`, and at its end it
deletes its own, whether it succeeded, failed or was cancelled. The file system could not
create, list, write or delete one of them. The error carries the path and the file system's
own message.

## Example
the scratch directory cannot be used at `.mergus/work/runs/0193a4f2`: Permission denied

## Fix
Check that the project's `.mergus/` folder is on a writable disk with free space, and that no
other program holds files in it open, then run again.
