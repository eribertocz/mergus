# MG-1308 · A file cannot be written

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1349, MG-REQ-1350

## Cause
The file system refused to create a file or a folder that `mergus init`, `mergus new model`
or `mergus add source` writes, for example because of its permissions.

## Example
`mergus init` in a folder the user running it may not write to.

## Fix
Make the folder writable by the user who runs Mergus, then run the command again.
