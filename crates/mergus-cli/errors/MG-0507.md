# MG-0507 · A cloud raw catalog has no connection value

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0515

## Cause
The `[raw]` zone uses the `cloud` profile, whose catalog is a PostgreSQL database named by a
secret reference, and the catalog was opened without the value of that secret. Nothing was
attached. The error names the secret reference, never its value.

## Example
the raw catalog `secret:raw_catalog` was opened without the value of its secret

## Fix
Store the connection of the catalog under the secret it names, for example with
`mergus secret set raw_catalog`, then run again.
