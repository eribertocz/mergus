# MG-0404 · Connected engine differs from the declared one

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0410

## Cause
Before reading any data from a database source, Mergus identifies the engine that answers: a
DuckDB file by its attach, which DuckDB refuses for a file of another format, and PostgreSQL by
`SELECT version()`, whose answer must start with `PostgreSQL`. The engine that answers differs
from the declared `engine`, or cannot be identified, which counts as different. No data was
read. The error names the source, the declared engine and the detected one.

## Example
Source `erp` declares engine `postgresql` but the engine that answers is
`CockroachDB CCL v24.1.0`.

## Fix
Point the source at a database of the declared engine, or declare the engine that answers.
For a DuckDB file, check that `location` names a `.duckdb` file.
