# MG-0311 · The same identifier twice in `ids.toml`

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0370

## Cause
Two entries of `ids.toml` have the same identifier, so two objects would share it. The error
names the line of the later entry and both keys.

## Example
`ids.toml` line 3: identifier `mdl_sw4a23b2ujmhopsw` is given to both `model.fact_orders` and
`model.fact_sales`

## Fix
Keep the entry of the object that had the identifier before its rename, and remove the other.
