# MG-0504 · A load returned the same key twice

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0518

## Cause
The current table `raw.<source>__<table>` holds one row per value of the table's `key`. One
load returned two rows with the same key, so neither can be chosen as the current one.
Nothing of the load was written to raw. The error names the source, the table and the key.

## Example
table `sales` of source `erp` returned the key `sale_id = 5` twice; nothing was written to raw

## Fix
Declare as `key` the columns that identify one row of the source table, such as
`key = ["sale_id", "line"]`, or remove the duplicate rows in the source.
