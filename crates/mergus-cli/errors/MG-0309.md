# MG-0309 · Literal secret in a configuration file

- Exit code: 6
- Retryable: no
- Rules: MG-REQ-0320, MG-REQ-0363

## Cause
A string value of `project.toml`, a folder `mergus.toml` or a `sources/*.toml` file is a
literal secret: a URL with a password in its user information, a private key, or a non-empty
value of a key that ends with `password`, `passwd`, `secret`, `token`, `api_key`, `apikey` or
`private_key`. The error names the file, the line and the key, never the value.

## Example
`sources/crm.toml` line 3: key `password` holds a literal secret; write a reference
`secret:<name>` instead.

## Fix
Store the value in a secret backend and reference it by name: `password = "secret:crm_password"`.
