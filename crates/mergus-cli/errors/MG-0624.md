# MG-0624 · A Python model makes data eager

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0616

## Cause
Steps return recipes, never data. The methods `collect`, `collect_async`, `fetch`,
`to_pandas`, `to_arrow` and `to_dicts`, and `DataFrame(...)` on the name `polars` is imported
as, load data into memory, anywhere in the file, private helpers included. The error names the
file, the line and the call.

## Example
`models/orders.py` line 10 column 12: `.collect()` makes the data eager; return the LazyFrame

## Fix
Return the LazyFrame. Mergus collects it once, when the step runs.
