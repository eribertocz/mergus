# MG-0701 · A secret a step needs does not resolve

- Exit code: 6
- Retryable: no
- Rules: MG-REQ-0721, MG-REQ-0720

## Cause
A step of the plan uses a source that references a secret as `secret:<name>`, and the
credentials gate of stage 4 found that the reference does not resolve: neither the
environment variable nor the keychain entry answers. The gate checks only that the reference
resolves; it never reads or prints the value. No step runs while a gate blocks.

## Example
MG-0701: gate `credentials`, model `stg_orders`, step `compute stg_orders`: the secret
`secret:crm` does not resolve; fix: run `mergus secret set crm`

## Fix
Run `mergus secret set <name>` to store the value in the keychain, then run again.
