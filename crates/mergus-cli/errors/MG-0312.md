# MG-0312 · Two objects have the same identifier

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0371

## Cause
Two objects of the project resolve to the same identifier: for example two models with the
same name, two columns with the same name in one table, or two tables with the same name in
one source. The error names both objects and the files that declare them.

## Example
model `fact_sales` (`models/staging/fact_sales.sql`) and model `fact_sales`
(`models/marts/fact_sales.sql`) have the same identifier `mdl_sw4a23b2ujmhopsw`

## Fix
Give one of the two objects another name.
