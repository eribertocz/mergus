# MG-0603 · SQL has a positional parameter

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0603

## Cause
A `.sql` model has a positional parameter, `?` or `$1`. Values that change per run are named
parameters: `$run_date`, `$period_start` and `$period_end`. The error names the file, the line
and column of the parameter and the parameter as written.

## Example
`models/marts/fact_sales.sql` line 3 column 18: parameter `?` is positional; run parameters
are named: `$run_date`, `$period_start` or `$period_end`

## Fix
Replace the parameter with the run parameter it stands for, such as `$run_date`.
