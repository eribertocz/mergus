# MG-0625 · A step parameter is positional-only

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0614

## Cause
A step has a parameter before `/`, so it can only be passed by position. Mergus passes every
input of a step by keyword, named after the parameter, so the call would fail when the step
runs. The error names the file, the line, the step and the parameter.

## Example
`models/orders.py` line 1 column 12: parameter `stg_orders` of step `orders` is
positional-only; Mergus passes every input by keyword, so move it after the `/`

## Fix
Remove the `/`, or move the parameter after it.
