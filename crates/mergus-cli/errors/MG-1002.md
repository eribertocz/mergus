# MG-1002 · The keychain cannot be written

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1007

## Cause
`mergus secret set` stores a value only in the keychain of the operating system, under the
service `mergus` and the account of the secret's name. The keychain could not be reached or
refused the entry, and Mergus never falls back to another store, so nothing is stored.

## Example
secret `secret:crm` cannot be stored in the keychain under service `mergus` and account
`crm`: no Secret Service is running

## Fix
Make the keychain of the platform available, then run the command again: unlock the
Keychain on macOS, start the Credential Manager service on Windows, or start a Secret
Service, such as GNOME Keyring or KWallet, on Linux.
