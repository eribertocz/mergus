# MG-1301 · Invalid command line

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1334, MG-REQ-1324

## Cause
The command line names an unknown command or option, gives an argument the command does not
take, or names no command. The error names the closest valid word.

## Example
`mergus valdate` is an unknown command; the closest command is `validate`.

## Fix
Use the valid word the message names, for example `mergus validate` instead of
`mergus valdate`.
