# MG-0502 · Raw catalog inside the project folder

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0515

## Cause
The DuckLake catalog of raw holds the key of every encrypted data file of raw, so it is
protected as a secret and never placed inside the project folder, where it could be
committed or shared with the project. With the `local` or `shared` profile its path, the
default `<location>/catalog.ducklake` or `<location>/catalog.sqlite` or the `catalog` of
`[raw]`, resolves inside the project root. Nothing was attached. The error names the path
and suggests one outside the project.

## Example
the raw catalog `lake/raw/catalog.ducklake` lies inside the project folder; it holds the
encryption keys of raw, so place it in a directory outside the project, such as
`/srv/sales-raw/catalog.ducklake`

## Fix
Set `catalog` in `[raw]` to a file outside the project folder, for example
`catalog = "/srv/sales-raw/catalog.ducklake"`, or move `location` outside it.
