# MG-0626 · A Python file is not valid Python

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0611

## Cause
A `.py` model or a `lib/*.py` module does not parse. Mergus reads Python files by their syntax
tree, without importing them, so a file that does not parse has no steps and no imports. The
error names the file, the line and the column when Python gives them, and Python's message.

## Example
`models/orders.py` line 1 column 12: not valid Python: invalid syntax

## Fix
Fix the syntax at the line and column given, then run again.
