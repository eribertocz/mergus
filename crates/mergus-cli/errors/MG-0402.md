# MG-0402 · Engine not allowed for the mode of a source

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0409

## Cause
A source in `live` or `connect` mode is read by the executor, so it must declare an analytical
`engine`: `live` allows `duckdb`, `ducklake`, `clickhouse`, `iceberg`, `delta` or `parquet`,
and `connect` allows `ducklake`, `iceberg` or `delta`, the formats with native versions. A
transactional database or an unknown engine is never queried by the executor. A `copy` source
of `kind = "database"` names the database Mergus reads in `engine`, `postgresql` or `duckdb`,
and a `copy` source of another kind declares no `engine`. The error names the file, the line,
the source and its mode.

## Example
`sources/erp.toml` line 3: source `erp` is read in `live` mode on engine `postgres`, which it
does not allow; `live` allows `duckdb`, `ducklake`, `clickhouse`, `iceberg`, `delta` or
`parquet`.

## Fix
Set `mode = "copy"`, with `engine = "postgresql"` or `engine = "duckdb"` for a `database`
source and no `engine` for another kind, and declare `fresh` on the models that need current
data.
