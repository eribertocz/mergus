# MG-1314 · An idempotency key is reused with other arguments

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-1313

## Cause
A command that changes state was given `--idempotency-key` with a key that another call used
less than 24 hours ago with other arguments. The key's record in `.mergus/idempotency/` keeps
the hash of the first call's arguments, and a key stands for one call only. Nothing is done.

## Example
`mergus new model orders --idempotency-key k1`, then `mergus new model customers
--idempotency-key k1`.

## Fix
Use a new key for a new call, or repeat the first call's arguments to get its result again.
