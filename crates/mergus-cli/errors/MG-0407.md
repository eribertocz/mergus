# MG-0407 · Key or incremental column without an index in the source

- Exit code: 0
- Retryable: no
- Rules: MG-REQ-0431

## Cause
A warning of `mergus doctor --source <name>`: the key or the incremental column of a declared
table has no index in the source. Keyset chunks are read in key order and incremental loads
filter on the incremental column, so without an index each read scans the whole table. In
phase 0.3 only PostgreSQL sources are checked. The warning names the table, the source and
the columns, with the index to create. It does not change the exit code.

## Example
The incremental column (updated_at) of table `orders` of source `erp` has no index in the
source; suggested index: `CREATE INDEX ON "public"."orders" ("updated_at");`

## Fix
Ask the owner of the source database to create the suggested index, or an index that starts
with those columns.
