# MG-0407 · A source cannot be inspected

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0431

## Cause
`mergus doctor --source <name>` attaches the source read-only, through its replica when it has
one, to read the indexes of its tables. The source could not be reached: no DuckDB is
available because there is no user cache directory for its extensions, or the connection
failed. Or it was reached but its catalog (`pg_index`) could not be read. The error names the
source and the reason.

## Example
Source `erp` cannot be reached: connection to server at "db.internal" failed: Connection
refused.

## Fix
Check that the source, or its replica, is reachable from this machine and that its connection
secret is right (`mergus doctor` shows where it resolves), then run the command again. Reading
`pg_index` needs no privilege beyond connecting.
