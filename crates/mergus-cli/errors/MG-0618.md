# MG-0618 · A Polars step failed

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0617

## Cause
Mergus calls each Polars step, the function of a model's Python file, in a Python child: once
with empty LazyFrames to plan it, and once with its inputs to run it. This step raised an
exception, returned something that is not a Polars LazyFrame, or raised an exception while
its result was collected, so it has no plan or no result. The error names the model, the step, and the exception's type and message, or the
type of what it returned.

## Example
MG-0618: model `sales`, step `in_usd`: ValueError: no rate for 2026-01-01

## Fix
Fix the step so it returns a LazyFrame, for example `return joined.with_columns(...)`. A step
is a plain function: call it from a Python test with a LazyFrame built by hand to reproduce
the error.
