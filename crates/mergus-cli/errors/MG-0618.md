# MG-0618 · A step is an async function

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0612

## Cause
A public top-level function of a `.py` model is an `async def`. Every public top-level
function is a step, and a step is a plain function that Mergus calls once and that returns a
recipe. The error names the file, the line and the function.

## Example
`models/orders.py` line 4: step `fetched` is an `async def`; a step is a plain `def`, or rename
it `_fetched` to make it a private helper

## Fix
Write the step as a plain `def`, or start its name with `_` to make it a private helper.
