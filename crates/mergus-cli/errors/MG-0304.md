# MG-0304 · Unknown configuration key

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0316, MG-REQ-0306, MG-REQ-0362, MG-REQ-0364, MG-REQ-0359, MG-REQ-0366

## Cause
A configuration file holds a key its schema does not allow at that place. Sources are not
declared in `project.toml`, and `include` is not a key. The error names the file, the line
and the closest allowed key, when one is close enough.

## Example
`project.toml` line 2: unknown key `mergos`; did you mean `mergus`?

## Fix
Rename the key to the suggested one, or remove it. Declare each source in its own
`sources/<source>.toml` file.
