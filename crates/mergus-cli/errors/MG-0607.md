# MG-0607 · A declared seed has no file

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0645

## Cause
`project.toml` declares `[seeds.<name>]`, but `seeds/<name>.csv` does not exist. The error
names the line of the declaration.

## Example
`project.toml` line 3: seed `cities` is declared but `seeds/cities.csv` is missing

## Fix
Add the file `seeds/<name>.csv`, or remove the declaration.
