# MG-0607 · The input of a history model has a NULL key

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0663

## Cause
A history model (`refresh = "history"`) reads a row whose `key` column is NULL. A NULL key
matches no version, so the row could be neither compared with its current version nor
closed. The run stopped and nothing was written to the history table.

## Example
the input of the history table `dim_customer` has a NULL in its key column `customer_id`

## Fix
Filter out or fill the rows with a NULL key in the model's input, for example with
`WHERE customer_id IS NOT NULL`, then run again.
