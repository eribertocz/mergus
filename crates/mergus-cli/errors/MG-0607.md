# MG-0607 · A history table is not rebuilt without --rebuild-history

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0665

## Cause
A full rebuild would drop or rewrite a history table (`refresh = "history"`), and the command
does not carry `--rebuild-history` with an interactive confirmation or `--yes`. History older
than raw retention cannot be recovered, so the table was kept as it was.

## Example
the history table `dim_customer` is not rebuilt without `--rebuild-history` and a confirmation

## Fix
Leave the history table out of the rebuild, or run again with `--rebuild-history` and confirm,
knowing that versions older than raw retention are lost.
