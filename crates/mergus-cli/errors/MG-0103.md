# MG-0103 · DuckDB rejected a model's SQL when the run executed it

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0710

## Cause
`mergus run` or `mergus backfill` executed a `.sql` model in its DuckDB session, and DuckDB
rejected the model's SQL: a parser, catalog or binder error, such as a table or a column that
does not exist in the session. The step failed before it wrote any row, and nothing was
published.

## Example
model `orders`: DuckDB rejected its SQL: Catalog Error: Table with name no_such_table does not exist!

## Fix
Correct the model's SQL as DuckDB's message says, then run again.
