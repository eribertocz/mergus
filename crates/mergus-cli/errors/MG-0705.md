# MG-0705 · A run limit stopped the run

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0718

## Cause
A run accepts limits on its wall time, the rows it writes and the bytes it scans, from
`[limits]` in `project.toml` or the `--max-wall-time`, `--max-rows-written` and
`--max-bytes-scanned` flags; when both are set, the smaller one applies. The run stopped before
it exceeded one of them: bytes scanned before stage 5 starts, rows written before the batch
that would cross the limit, wall time before a segment or between batches. Nothing was
published. Complete candidates are kept for the next run. The error names the limit, its value
and the amount reached.

## Example
the run stopped at its limit `rows_written` of 1000000 rows: it reached 1000250 rows

## Fix
Raise the limit in `[limits]` or with its flag, or select fewer models, then run again.
