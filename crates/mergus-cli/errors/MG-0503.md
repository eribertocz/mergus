# MG-0503 · Raw catalog not encrypted

- Exit code: 1
- Retryable: no
- Rules: MG-REQ-0515

## Cause
Raw is stored encrypted at rest: its DuckLake catalog is attached with the `ENCRYPTED`
option, so every data and delete file is encrypted with a key of its own. The catalog of raw
already exists and was created without encryption, and Mergus never writes raw unencrypted.
Nothing was written. The error names the catalog: its file, or the secret reference of its
connection.

## Example
the raw catalog `/srv/raw/catalog.ducklake` is not encrypted; Mergus never writes raw
unencrypted

## Fix
Point `[raw]` at a new catalog, which Mergus creates encrypted, and extract again; delete the
unencrypted catalog and its data files once nothing reads them.
