# Code of conduct

Mergus adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in the project, in its repository, issues, pull
requests and other project spaces, is expected to follow it.

## Enforcement

The enforcement contact is the repository owner, GitHub user
[`eribertocz`](https://github.com/eribertocz). Report instances of abusive, harassing or
otherwise unacceptable behavior to the owner. Reports are handled as the Contributor Covenant
2.1 describes, and the privacy and security of the reporter are respected.
